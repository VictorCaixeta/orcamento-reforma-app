# Apartment Renovation — Carol & Victor

Front-end repository for Carol and Victor's apartment renovation project. Built with React and Vite for prototyping and previewing layouts and styles.

## Technologies

- React
- Vite
- CSS (see `src/index.css` and `src/App.css`)
- ESLint (basic configuration)

## Project structure

- `src/` — React source code
- `public/` — static assets (favicon, etc.)
- `index.html` — HTML entry point
- `package.json` — scripts and dependencies

## Requirements

- Node.js 16 or newer
- npm or yarn

## Installation

1. Install dependencies:

```
npm install
```

2. Run development server with hot-reload:

```
npm run dev
```

3. Build for production:

```
npm run build
```

4. Preview the production build locally:

```
npm run preview
```

## Useful scripts (in `package.json`)

- `dev` — starts the development server
- `build` — creates optimized production files
- `preview` — serves the production build for preview

## How to contribute

- Create a branch from `develop` for new features or fixes.
- Open a pull request describing your changes.

## Contact

If you have questions or suggestions, open an issue or contact the maintainers.
